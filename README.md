# Creators Desk (`creators-desk`)

> Enterprise-grade workspace for lore management and creative multi-project orchestration.

---

## Overview

**Creators Desk**는 소설 집필, 인터랙티브 미디어/게임 기획, 테크니컬 블로그 등 다각화된 IP 자산과 제작 파이프라인을 체계적으로 조율하기 위한 크리에이티브 오케스트레이션 플랫폼입니다.

분산된 아이디어와 방대한 설정 데이터(Lore)의 정합성을 보장하고, 기획부터 릴리즈까지 이어지는 제작 파이프라인 전반을 단일 인터페이스에서 통합 관리할 수 있는 프로덕션 환경을 제공합니다.

---

## Key Capabilities

### Lore &amp; Worldbuilding Consistency

- 인물, 세력, 연대기, 고유 명사 등 핵심 IP 설정 데이터베이스의 버전 관리 및 정합성 검증
- 매체 간(트랜스미디어) 설정 충돌을 방지하기 위한 엔티티 교차 참조(Cross-Referencing) 시스템

### Multi-Project Pipeline Management

- 시나리오 드래프트, 게임 마일스톤, 기술 아티클 발행 등 멀티 트랙 워크플로우 통합 트래킹
- 프로젝트 간 종속성 관리 및 단계별 납기/진척도 시각화

### Distraction-Free Technical Writing

- 창작 생산성을 극대화하는 미니멀리스트 텍스트 엔진
- 마크다운 기반의 정형화된 데이터 아카이빙 및 확장 가능한 스키마 구조

---

## Architecture &amp; Technology Stack

- **Core Engine**: TypeScript
- **Runtime / Framework**: Modern High-Performance Web Architecture
- **Data Layer**: Local-first Persistence &amp; Cloud Synchronization Infrastructure

## Quick Start

### System Requirements

- Node.js 20.x LTS or higher
- Package Manager: `pnpm`, `npm`, or `yarn`

### Installation &amp; Deployment

```bash
# Clone the repository
git clone https://github.com/Sunggu/creators-desk
cd creators-desk

# Install dependencies
npm install

# Run development environment
npm run dev

# Production build
npm run build
```
