## 1. 배경 및 문제 상황 (Context)

- 웹 배포 사이트(`https://creator.binarygap.com/`) 접속 시 일반적인 웹 서비스식 "새 Vault 만들기" 모달 카드 화면이 먼저 노출됨.
- 옵시디언 특유의 앱 경험(좌측 리본 바, 파일 탐색기 사이드바, 상단 탭 바, 하단 상태바, 다크 모드 톤앤매너)이 부재하여 "웹으로 옮긴 옵시디언"이라는 정체성이 체감되지 않는 문제 발생.

---

## 2. 핵심 결정 및 변경 사항 (Decisions)

### ① Zero-Friction 첫 진입 경험
- 첫 방문 시 빈 생성 카드를 보여주는 대신, 자동으로 기본 `Main Vault`와 `Welcome.md` 노트를 즉시 프로비저닝하고 로드.
- 접속 1초 만에 곧바로 옵시디언 에디터 작업 환경에 진입하도록 전환.

### ② 옵시디언 데스크톱 3단 레이아웃(Desktop Chrome) 완전 이식
- **Ribbon (좌측 44px)**: 탐색기 토글, 검색, 하단 Vault 스위처 아이콘, 설정 아이콘.
- **Sidebar (파일 탐색기, 256px)**: Vault 드롭다운 헤더(`Main Vault ▾`), 탐색기 툴바, 파일/폴더 트리.
- **Tab Bar (상단 36px)**: 활성 노트 탭 표시, 닫기(`×`), 새 노트(`+`).
- **Status Bar (하단 24px)**: 백링크 수, 실시간 단어/글자 수, 커서 위치(`Ln/Col`), 자동 저장 상태 인디케이터.

### ③ Vault 관리를 모달로 전환
- Vault 전환 및 생성 기능을 전체 화면 차단 카드가 아닌, 옵시디언 고유의 팝업 모달(`ObsidianVaultModal`)로 분리.
- 리본 바 하단 아이콘이나 사이드바 헤더를 누르면 언제든 즉시 팝업.

### ④ 옵시디언 다크 테마 디자인 토큰
- 에디터 배경 `#1e1e22`, 사이드바 `#18181b`, 리본/상태바 `#121215`, 보더 `#26262e`.
- 옵시디언 시그니처 바이올렛 액센트(`violet-500` / `#a78bfa`) 적용.
